# CCNA Lab 01: Switch & Router Interface Configuration

## 📋 Lab Overview
This lab covers basic configuration, security hardening, and interface management on Cisco routers and switches (Chapter 9 concepts).

## 🛠️ Configuration Steps Implemented:
1. **Device Identification:** Configured custom hostnames for routers and switches (`R1`, `SW1`, `SW2`).
2. **IP Addressing:** Assigned proper IPv4 addresses to network devices and end hosts (`PC1` - `PC4`).
3. **Speed & Duplex Hardening:** Manually configured interface speed and duplex modes to prevent auto-negotiation mismatches and collisions.
4. **Interface Documentation:** Added descriptive descriptions (`description`) to interfaces for better network management and troubleshooting.
5. **Security Best Practices (Port Security):** Administratively disabled (`shutdown`) all unused switch ports to prevent unauthorized physical access.
